# 测试分析文档

> 作者：测试工程师
> 版本：v4.2

## 1. 测试策略

本项目为纯静态站点，采用手工功能测试为主。无自动化测试框架。

| 层级 | 覆盖内容 | 执行方式 | 频率 |
|---|---|---|---|
| 冒烟测试 | 构建成功 + 页面 200 | `npm run build` | 每次修改 |
| 功能测试 | 搜索、详情页、多语言、对比、职位 | 手工 + HTTP | 版本发布前 |
| 兼容性测试 | 浏览器适配 | 手工 | 大版本更新 |
| 性能测试 | 页面加载、搜索响应 | 手工 | 数据量级变化时 |

## 13. 已知限制

| 限制 | 说明 |
|---|---|
| 无自动化测试 | 纯手工，需人工验证 |
| CI/CD 已集成 | `.github/workflows/ci.yml` 自动构建验证 |
| 搜索索引全内存 | 数据量 > 1000 时需优化 |
| 对比逻辑内联 | compare 页面脚本嵌在模板，未抽成独立文件 |
| 无 404 页面 | 不存在路径返回首页 200 |
| 位置计数非递归 | 公司级职位数不包含子部门职位 |
