## 关键决策

| 决策 | 选项 | 选择理由 | 放弃的方案 |
|------|------|----------|-----------|
| 分支数量 | 三分支 vs 双分支 | 双分支无法隔离"开发"和"数据贡献" | develop→main 两分支 |
| 数据校验时机 | CI 强制校验 vs 手动 | CI 自动校验防止不合格 PR 合并 | 只靠人工审查 |
| sourceBase 策略 | BRANCH 环境变量替换 | 同一 config 适配不同分支 | 各分支维护不同 config |
