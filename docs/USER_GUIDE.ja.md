## 企業信誉照会システムとは？

企業信誉照会システムは、企業の評判を簡単に調べられるプラットフォームです。残業は多い？福利厚生は？企業文化は？実際の職場環境を知ることができます。

## クイックスタート

### 1. 企業を検索

トップページの検索ボックスに会社名を入力：

- 「華為」「字節跳動」「Tencent」などを入力
- 入力すると自動で検索候補が表示されます
- 候補をクリックして直接ジャンプ、またはEnterキーで全結果表示

### 2. 検索結果を表示

検索結果には各企業の：
- **名前**と**説明**
- **総合評価**と**レビュー数**
- **都市**、**企業規模**、**業界**

結果は関連性の高い順に表示されます。

### 3. 企業詳細を閲覧

企業をクリックして詳細ページへ：

#### 🏢 基本情報
- 会社名（和英）、業界
- 都市、企業規模
- 設立年、公式サイト
- 会社概要

#### ⭐ 総合評価
右上の大きな円が総合評価を表示（5点満点）。

#### 📊 8つの主要指標

| 指標 | 説明 | 高得点＝ |
|---|---|---|
| 仕事の強度 | タスクの密度とプレッシャー | より強い |
| 残業頻度 | 残業の頻度 | 残業多い |
| 給与水準 | 報酬の競争力 | 給与高い |
| 福利厚生 | 福利厚生の充実度 | 福利厚生良い |
| ワークライフバランス | 仕事と私生活の境界 | バランス良い |
| キャリア成長 | 昇進・成長の機会 | 成長しやすい |
| 職場環境 | オフィス環境と雰囲気 | 環境良い |
| 企業文化 | 価値観と文化 | 文化良い |

#### ⚠️ 996警告
996勤務制の企業は黄色い警告バーが表示されます。

#### 📝 詳細説明
- **残業状況**：日常の残業時間、週末の頻度
- **福利厚生**：給与構成、手当、保険
- **企業文化**：内部の雰囲気、マネジメントスタイル
- **メリット・デメリット**：従業員視点の評価

### 4. ディスカッションに参加

ページ下部のコメント欄で：

- GitHubアカウントでログイン（Giscus経由）
- 企業に関する意見を投稿
- 他のコメントに返信
- コメントにリアクション

## 企業データの追加・編集方法

このプロジェクトは **Markdownファイル** を使用して企業データを保存しています。

### Markdown形式

```markdown
会社名
===

簡単な会社説明。

## 基本情報

- 英文名：ByteDance
- 別名：ByteDance, 抖音
- 都市：北京
- 規模：10000人以上
- 設立：2012
- 業界：インターネット/テクノロジー
- サイト：https://www.example.com

## 仕事の強度

スコア：4.5/5

## 残業頻度

スコア：4.2/5

## 996ですか

はい

## 給与水準

スコア：4.8/5

## 残業状況

説明文...

## メリット

メリット文...

## デメリット

デメリット文...
```

### 開発環境での追加

```bash
# 1. companies/ディレクトリに.mdファイルを作成
vim companies/会社名.md

# 2. 静的サイトを再構築
npm run build

# 3. プレビュー
cd dist && python3 -m http.server 8080
```

## よくある質問

### Q: データの出典は？
ユーザーの自発的な貢献によるものです。参考程度にご利用ください。

### Q: 誤った情報の報告方法は？
GitHub Issues またはコメント欄で報告してください。

### Q: 総合評価の計算方法は？
（給与＋福利厚生＋WLB＋キャリア＋環境＋文化）÷ 6
