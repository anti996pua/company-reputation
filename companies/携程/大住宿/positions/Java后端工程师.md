Java 后端工程师
============

负责携程大住宿事业群的酒店预订核心系统开发与架构优化。

类别: 研发
职级范围: T3 - T7
工作地点: 上海

## 基本信息

- 招聘人数：15
- 面试形式：3 轮技术面 + HR 面
- 日文名：Javaバックエンドエンジニア
- 标签：互联网/旅游/大厂/上海/Java/分布式

## 薪资范围

- T3: 16-25K × 15-16 薪（总包 24-40 万）
- T4: 25-35K × 15-16 薪（总包 38-56 万）
- T5: 35-50K × 15-16 薪（总包 52-80 万）
- T6: 50-70K × 15-16 薪（总包 75-112 万）
- T7: 70-100K × 15-16 薪（总包 105-160 万）

## 技能要求

- 精通 Java，熟悉 JVM 调优与并发编程
- 熟练使用 Spring Boot/Spring Cloud 微服务框架
- 掌握 MySQL 数据库设计与优化（分库分表/读写分离）
- 熟悉分布式中间件（Redis/Kafka/RocketMQ）
- 了解高并发/高可用系统设计（限流/降级/熔断）
- 有 OTA/电商行业经验优先

## 面试流程

1. 简历筛选：Java 开发经验 + 项目规模
2. 技术一面（60min）：Java 基础 + JVM + 并发编程
3. 技术二面（60min）：微服务架构 + 分布式事务方案
4. 技术三面（45min）：系统设计（酒店库存/价格/订单）
5. HR 面：定级、薪资

## 技术栈

Java, Spring Boot, Spring Cloud, MySQL, Redis, Kafka, RocketMQ, JVM, Docker, K8s, 微服务, 分布式, MyBatis, Sentinel, Nacos
