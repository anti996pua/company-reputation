示例职位
========

这是一个示例职位，展示如何添加公司/部门下的职位信息。下面每个 `##` 数据章节后面都有一个 `## 📖 填写说明` 章节解释该字段的填写方法。

类别: 研发
职级范围: P5 - P8
工作地点: 线上
类似职位: 贡献指南/示例部门(示例职位)

## 薪资范围

- P5: 20-30K × 14-16 薪（总包 28-48 万）
- P6: 28-40K × 14-16 薪 + 期权 0-2K/月（总包 39-66 万）
- P7: 40-55K × 14-16 薪 + 期权 2-5K/月（总包 56-94 万）
- P8: 55-75K × 14-16 薪 + 期权 5-12K/月（总包 84-140 万）

## 📖 填写说明

每行格式：`- 职级: 月薪范围 × 年终月数 薪（总包 范围）`。职级不一定要连续，可以只列出实际的职级。

## 技术栈

Java, Python, Go, Spring Boot, MyBatis, Redis, MySQL, PostgreSQL, Docker, Kubernetes, Git, Jenkins

## 📖 填写说明

技术栈用逗号（`,`）或顿号（`、`）分隔。也可以用分类格式：

```
编程语言：Java, Python, Go
框架：Spring Boot, MyBatis, Redis
数据库：MySQL, PostgreSQL
工具：Docker, K8s, Git
```

## 技能要求

1. 计算机/软件工程等相关专业本科及以上
2. 精通 Java/Python/Go 至少一门编程语言
3. 熟悉分布式系统设计，有微服务架构经验
4. 有高并发、高性能系统设计和优化经验
5. 良好的沟通能力和团队协作能力

## 📖 填写说明

逐行列出硬性要求和软性要求，一般为 3-8 条。每行以数字（`1.`）或连字符（`-`）开头。

## 面试流程

1. 简历筛选：HR 电话沟通意向和基本信息
2. 技术一面：算法 + 数据结构（在线 coding）
3. 技术二面：系统设计 + 项目深入
4. 交叉面：其他部门的技术负责人
5. HR 面：薪资沟通 + 入职时间
6. 发 offer

## 📖 填写说明

逐行列出面试步骤，步骤数一般为 3-6 轮，每步简要说明考核内容。

## 类似职位

- 腾讯/IEG/天美工作室/嵌入式开发工程师
- 字节跳动/抖音/客户端开发工程师

## 📖 填写说明

格式：`- 公司名/部门名(可嵌套多层)/职位名`

这个字段实现"双向跳槽参考"：A 公司的职位页面会显示 B 公司的类似职位，B 公司的页面也会显示 A 公司的。

## 基本信息

- 标签：示例, 教学, 职位模板
- 招聘人数：5
- 面试形式：2 轮技术面 + 主管面 + HR 面
- 英文名：Example Position
- 日文名：サンプルポジション

## 📖 填写说明

`## 基本信息` 中的可选字段：

| 字段 | 格式 | 说明 |
|---|---|---|
| `标签` | `标签1/标签2` | 用 `/` 分隔，用于搜索匹配 |
| `招聘人数` | 纯数字 | 计划招聘人数 |
| `面试形式` | 自由文本 | 简述面试轮次 |
| `英文名` | 文本 | 用于英文搜索 |
| `日文名` | 文本 | 用于日文搜索 |

## 员工评价

### 2025-06-01 | 示例岗位 | 2 年 | @template_user

> 这是一个示例评价。请根据真实工作体验撰写，用 `>` 开头的段落作为引言。

评分：3.5/5

**优点**
这是一个示例公司，展示了如何写评价

**缺点**
不是真实公司，评分仅供参考

## 📖 填写说明

评价格式：

```
### 日期 | 角色/岗位 | 工作年限 | @用户名

> 评价正文（用 > 开头）

评分：X.X/5

**优点**
优点列表（逐行列出）

**缺点**
缺点列表（逐行列出）
```

- 日期格式：YYYY-MM-DD
- 评分格式：X.X/5
- 优点/缺点：用 `**优点**` 和 `**缺点**` 作为二级标题

## 💡 文件命名规范

职位文件名用完整中文名：

```
嵌入式软件工程师.md        ✅
前端开发工程师.md          ✅
soft-engineer.md           ⚠️ 尽量用中文名
```

文件位置：`companies/公司名/部门名/positions/文件名.md`

不要含特殊字符：`/ \ : * ? " < > |`
