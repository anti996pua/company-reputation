贡献指南 — 如何添加公司数据
=======================

欢迎！本文档是一份"活的"模板，手把手教你如何在本站添加一家公司。每个 `##` 章节后面都有一个对应的 `## 📖 填写说明` 章节，解释了该字段的填写方法和注意事项。

**快速开始**：
1. 复制 `companies/华为.md` 或本文件
2. 清空所有 `📖 填写说明` 章节和本说明段落
3. 填入你的公司真实数据
4. 运行 `npm run build` 验证

## 基本信息

- 英文名：Contribution Guide
- 日文名：コントリビューションガイド
- 别名：模板, guide, template, 贡献指南
- 标签：贡献指南/模板/示例/教学
- 城市：线上（全球）
- 规模：开源项目
- 成立：2024
- 行业：互联网/科技
- 官网：https://github.com

## 📖 填写说明

`## 基本信息` 中的每一行是一个数据字段，格式固定为 `- 字段名：值`。

| 字段 | 是否必需 | 说明 | 示例 |
|---|---|---|---|
| `英文名` | 推荐 | 用于英文搜索匹配 | `Huawei` |
| `日文名` | 推荐 | 用于日文搜索匹配 | `ファーウェイ` |
| `别名` | 推荐 | 逗号分隔，支持多名称搜索 | `Huawei, 华为技术` |
| `标签` | 推荐 | 用 `/` 分隔，用于分类和搜索 | `通信设备/5G/大厂/深圳` |
| `城市` | 推荐 | 公司总部城市 | `深圳` |
| `规模` | 推荐 | 公司规模 | `约 19.5 万人` |
| `成立` | 推荐 | 成立年份（纯数字） | `1987` |
| `行业` | 推荐 | 所属行业 | `互联网/科技` |
| `官网` | 推荐 | 官方网址 | `https://www.huawei.com` |

所有字段都可以省略，但填得越多搜索匹配效果越好。

## 📖 评分填写说明

每个评分指标格式：`评分：X.X/5`，评分范围 1.0 - 5.0。

| 评分 | 含义 |
|---|---|
| 5.0 | 极高（如 996、长期通宵）|
| 4.0 | 较高（经常加班）|
| 3.0 | 中等（偶尔加班）|
| 2.0 | 较低（基本不加班）|
| 1.0 | 很低（955 工作制）|

评分指标说明：

| 指标 | 关注点 |
|---|---|
| `工作强度` | 任务量和压力水平 |
| `加班频率` | 加班的频繁程度（侧重频率） |
| `是否996` | 填 `是` / `否` / `部分部门是` |
| `薪资水平` | 相对市场水平 |
| `福利待遇分` | 五险一金、补贴、股票等 |
| `工作生活平衡` | 个人时间保障程度 |
| `职业发展` | 晋升通道、培训资源 |
| `工作环境` | 办公环境、设备配置 |
| `企业文化分` | 价值观、管理风格 |

评分后面可以跟一段描述文字说明具体情况：

```
评分：4.5/5

终端业务因产品竞争激烈，发布前普遍进入封闭开发模式，项目攻坚期 10-10-6 是常态。
```

## 💡 添加部门

在公司目录下创建子目录来添加部门：

```
companies/
├── 华为.md
├── 华为/
│   ├── 终端BG.md
│   ├── 终端BG/
│   │   ├── 手机产品线.md
│   │   └── positions/
│   │       └── 嵌入式软件工程师.md
├── 腾讯.md
└── 腾讯/
    ├── IEG.md
    └── IEG/
        └── 天美工作室.md
```

**规则**：
- 目录名和 `.md` 文件名通常一致（如 `华为/终端BG/终端BG.md`）
- 支持任意深度嵌套
- 部门标题格式：`公司 - 部门` 或 `公司 - 上级部门 - 部门`

部门文件与公司文件格式完全一致，额外支持 `- 所属公司：华为` 字段。

详细示例请看本公司的 `示例部门`。

## 💡 添加职位

在公司或部门下创建 `positions/` 目录来添加职位：

```
华为/终端BG/positions/
├── 嵌入式软件工程师.md
├── 前端开发工程师.md
└── 后端开发工程师.md
```

**职位必需章节**：`薪资范围` `技术栈` `技能要求` `面试流程` `类似职位`

详细示例请看 `示例部门` 下的 `示例职位`。

## 💡 多语言搜索

填好以下字段即可支持多语言搜索：

- `英文名` → 让英文搜索匹配（如 `Huawei`）
- `日文名` → 让日文搜索匹配（如 `ファーウェイ`）
- `别名` → 额外的名称变体（如 `Huawei, 华为技术`）

搜索优先级：中文名 > 英文名 > 日文名 > 别名 > 标签
