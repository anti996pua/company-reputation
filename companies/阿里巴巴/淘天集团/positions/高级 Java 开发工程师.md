高级 Java 开发工程师
====================

负责阿里淘天电商核心系统的服务端开发。

类别: 研发
职级范围: P5 - P8
工作地点: 杭州/北京

## 职位描述

淘天集团（淘宝/天猫/1688）核心电商系统的服务端开发，参与双 11 大促、交易链路、广告投放等核心场景的技术建设。系统规模大、技术挑战高。

## 基本信息

- 招聘人数：30
- 面试形式：3-4 轮技术面 + 1 轮 HR 面
- 日文名：シニアJava開発エンジニア
- 标签：互联网/电商/云计算/大厂/杭州/后端/Java

## 薪资范围

- P5: 28-38K × 16 薪（校招起薪）
- P6: 35-48K × 16 薪 + 股票 0.5-2K/月
- P7: 48-65K × 16 薪 + 股票 3-8K/月（总包 80-130 万）
- P8: 65-85K × 16 薪 + 股票 8-20K/月（总包 130-200 万）

## 技能要求

- 精通 Java（JVM 调优、并发编程、性能优化）
- 深入理解 Spring Cloud / Dubbo / Sentinel 等微服务体系
- 熟悉 MySQL InnoDB 原理（事务隔离级别、索引优化、锁机制）
- 掌握分布式事务（TCC/Saga/Seata）、消息队列（RocketMQ/Kafka）、缓存（Tair/Redis）
- 有万亿级流量场景（双 11）经验优先
- 熟悉 Kubernetes / Docker 容器化部署

## 面试流程

1. 简历筛选：HR 初步评估匹配度
2. 在线笔试：限时 90 分钟，算法 + SQL + Java 基础
3. 技术一面（45min）：Java 基础、JVM、并发编程、项目深挖
4. 技术二面（60min）：分布式系统设计、高并发架构、DDD 领域建模
5. 交叉面（45min）：跨部门 P8/P9 面试，侧重工程思维和系统设计
6. 终面（30min）：技术总监/主管面，考察技术视野和职业规划
7. HR 面（30min）：背景调查、薪资期望、入职时间
8. 薪酬沟通：HR 根据面评定 P 级，发正式 Offer

## 技术栈

Java, JVM, Spring Cloud, Dubbo, Sentinel, MySQL, RocketMQ, Tair, HBase, Elasticsearch, Flink, Docker, Kubernetes, Arco
